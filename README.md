# 예비지도

2027년 육군 단기 상비예비군 공고를 사단·동원지원단 수준에서 탐색하는 로컬 웹앱이다. 병과와 전역계급을 선택하면 조건에 맞는 직책이 있는 부대만 지도와 목록에 표시한다.

배포 주소: **https://viokorea.github.io/reserve-map/**

## GitHub Pages 배포

`main` 브랜치에 푸시하면 GitHub Actions가 의존성 설치, 테스트, 프로젝트 경로용 빌드를 수행하고 Pages에 배포한다. 저장소 Settings → Pages의 Source는 GitHub Actions다. 기존 다른 Pages 프로젝트와 별도 경로를 사용한다.

```sh
npm run build -- --base=/reserve-map/
npm run preview -- --base=/reserve-map/
```

데이터·PDF·홈 링크는 Vite의 `BASE_URL`을 사용하므로 `/reserve-map/`에서도 동작한다. 로컬 원본 PDF, Graphify 캐시와 미리보기 이미지는 Git에서 제외하고 앱에 필요한 공개 공고 사본만 `public/data/`에 포함한다.

## 실행

Node.js 22.12 이상 또는 24 이상을 권장한다.

```sh
npm install
npm run dev
```

터미널에 표시된 Local 주소를 연다. 기본 포트가 사용 중이면 Vite가 다음 포트를 선택한다. 현재 개발 미리보기는 `http://127.0.0.1:5174/`에서 실행했다.

```sh
npm test
npm run build
npm run preview
```

React·TypeScript·Vite·Leaflet을 사용한다. 지도는 API 키 없이 OpenStreetMap 타일로 작동하며, 네이버 지도 검색과 병무청 공식 찾아가는 길로 연결한다. 사용자 위치는 위치 버튼을 누르고 브라우저 권한을 허용한 경우에만 사용하며 저장하지 않는다. 병과·계급 등 검색 조건은 공유할 수 있도록 현재 페이지 URL에 반영한다.

## 데이터와 범위

- 원본은 폴더에 제공된 45쪽 「'27년 육군 단기 상비예비군 정기모집 및 선발 공고」다. 앱에서 각 직책의 PDF 쪽수를 열 수 있다.
- 5개 동원사단, 10개 동원지원단, 12개 지역방위사단, 동원자원호송단 등 **28개 상위 부대**를 제공한다. 군단·군수·민사 등 나머지 모집은 이번 범위에 포함하지 않는다.
- 원문 표 767행을 적용 부대에 연결해 1,652개 항목을 구성했다. 공통 표를 여러 부대에 연결하므로 원문 행 수와 앱의 항목 수는 다르다. 항목 수는 실제 모집인원 합계가 아니다.
- 원문 지원가능계급이 불완전한 1행은 5개 동원사단에 적용되어, 기본 탐색의 확정 항목은 1,647개다. 누락 항목은 추가 확인으로 보존한다.
- 모집 인원은 ‘사단 1명’, ‘여단 1명’, ‘대대 1명’ 등 원문 단위를 유지한다. 알 수 없는 예하부대 수를 곱하지 않는다.
- 73사단 보병대대는 공고 17~18쪽 A/B 시범 표를 사용한다. 일반 표의 보병대대와 중복 적용하지 않는다.

위치는 사용자와 합의한 대로 **상위 부대 권역의 대략 위치**로 제공한다. 지도 좌표는 지역 대표 근사치이며 검증된 본부·출입구 좌표가 아니다. 여단·대대 항목도 해당 상위 부대 근처로 가정한다. 실제 예하부대가 다른 시·군에 있을 수 있으며 상세와 이용 안내에 표시한다. 일부 동원사단에는 공식 훈련장 안내·공개 주소를 덧붙였다. 참고 주소는 실제 근무지·집결지와 별도로 확인해야 한다.

## 판정 기준과 한계

선발계급이 아닌 직책별 `지원가능계급` 목록을 사용한다. 병과 별칭을 정규화하고, 원문 병과·계급·직책 그룹·쪽수를 함께 보존한다. 전투공통·군수공통·공통은 모든 병과 허용으로 확장하지 않는다.

유사 지원은 공고 10쪽에서 확인되는 장교 병과 방향과 일부 부사관 특기 규칙을 적용한다. 상세 특기를 요구하지만 자료가 충분하지 않은 병·부사관 규칙 전체를 구현한 것은 아니다. 원문에서 특기가 명시된 직책은 특기 미선택 시 추가 확인으로 분류한다. 계급과 병과 일치는 연령, 거주지, 보류, 동원대상, 소집 참석 등 전체 지원자격을 보장하지 않는다.

공고 11쪽은 시작일이 2026년, 종료일이 2025년으로 적혀 있다. 종료연도를 자동 수정하지 않고 접수 일정 확인 필요로 표시한다.

## 원문에서 데이터 다시 만들기

```sh
uv run --with pdfplumber python scripts/extract_recruitments.py
```

이 명령은 루트의 첫 PDF를 읽어 `public/data/recruitments.json`, `public/data/extraction-audit.json`과 웹에서 열 수 있는 이름의 PDF 사본을 만든다. 원본은 변경하지 않는다. 이 스크립트의 표 연결은 현재 공고 레이아웃에 맞춘 것이므로 다른 공고에 그대로 적용하면 안 된다. 원문 표와 적용 범위를 먼저 확인한다.

## 검증

판정·계급 예외·유사병과 방향·특기·73사단 적용·검색·URL 공유·데이터 참조를 확인하는 Node 테스트 13개를 제공한다. 실제 Chrome에서 병과·계급 선택, 상세와 원문 링크, 없는 검색 결과, 320·375·414·768px 화면을 확인했다. 색상 대비는 본문·보조문구·강조 버튼·확인 필요 배지를 검증했다.

Graphify 자료는 `graphify-out/`에 있으며 공고 해석 보조 자료다. 앱은 해당 자료나 별도 서버·DB에 의존하지 않는다. 초기 구현과 원문에서의 데이터 추출은 완료했으며, 각 모집부대의 최신 근무지·주소 확인과 공고 변경 반영은 별도 운영 검수가 필요하다.
